# AIS-catcher-VTS-rijnmond-blok-layer

add layer to ais.catcher map
Install:

sudo mkdir -p /etc/AIS-catcher/plugins
sudo curl -L https://raw.githubusercontent.com/EyeVisionsNL/AIS-catcher-VTS-rijnmond-blok-layer/main/vts-sectoren-rws-v11.pjs
sudo chmod 644 /etc/AIS-catcher/plugins/vts-sectoren.pjs
check plugin dir: /etc/AIS-catcher/plugins
check
head -5 /etc/AIS-catcher/plugins/vts-sectoren.pjs
